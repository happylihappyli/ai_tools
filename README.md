# AI Tools 集合

这是一个用于辅助 AI 编程和开发流程的工具集，主要包含两个核心工具：**图形化编译工具**和**步骤查看工具**。

## 核心原则与推荐

**强烈推荐用户使用 C++ 版本，而不是 Python 版本。**

作为开发规范：**Python 版本中已有的所有功能，都必须在 C++ 版本中实现（对齐）。** 这样可以保证 C++ 版本的完整性、运行效率和稳定性，未来主要维护方向为 C++ 版本。

## 工具列表

### 1. 图形化编译工具
- 提供直观的编译进度条、总耗时显示。
- 捕获并展示编译提示信息，支持将编译结果保存至文件。
- 方便人类开发者和 AI Agent 查看编译详细信息（如编译文件、编译选项、编译结果）。
- 提供基于 Qt 的用户界面。
   
### 2. 步骤查看工具
- 任务步骤跟踪工具，可视化当前机器及 Agent 正在执行的总目标与子目标。
- 类似流程图展示，每个子目标都有编号，支持节点点击查看详细信息。
- 允许 AI 和用户更新、添加、修改、删除节点。
- 帮助用户直观理解当前的探索步骤和后续规划，同时为 AI 提供参考以便制定下一步操作。

## 目录结构
- `cpp_panel/`: C++ 版本的实现目录（推荐使用该版本进行构建和运行）。
- `compile_tool.py` / `step_tracker.py` 等: Python 版本的实现（可作为快速启动、修改配置或原型参考，但功能需在 C++ 中全量实现）。
- `图形化编译工具.md`: 编译工具的需求与设计说明。
- `步骤查看工具.md`: 步骤查看工具的需求与设计说明。
